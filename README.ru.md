# Вычислительная физика наночастиц: плазмоны, поляритоны, экситоны, спектры

Цель проекта — строить численные модели оптических и колебательных характеристик наночастиц
(плазмоны, поляритоны, экситоны и их взаимодействие; спектры поглощения/экстинкции, флуоресценции,
рамановские и бриллюэновские спектры), сравнивать их с экспериментом и уточнять теоретические
модели через анализ невязки «модель − эксперимент» и выявление латентных (неучтённых) переменных.

## Структура

| Каталог | Назначение |
|---|---|
| `books and articles/` | Книги и статьи (PDF), источник для обзора литературы |
| `docs/` | Методология, обзоры методов, описание баз данных (`.md`, правятся по мере уточнения) |
| `docs/methods/` | Подробные заметки по отдельным методам расчёта |
| `software/` | Код (C++20, Qt6 GUI, bash-скрипты), см. [software/README.md](software/README.md) |
| `data/reference/` | Справочные данные из открытых баз (структуры, оптические константы, фононы, спектры) |
| `data/experiment/` | Экспериментальные данные (с метаданными измерений) |
| `data/results/` | Результаты расчётов и сравнений |
