# Аудит модели «агрегат + наночастица» и графики ssp_gui

> 2026-11-15. Объект: `ssp_aggregate` / `ssp_gui` v0.3 и методика [methods/aggregate_plexciton_model.md](../methods/aggregate_plexciton_model.md).
> Вопрос: насколько результаты пригодны для количественных выводов и сравнения с экспериментом; что исправить.
> Проверки, на которые опирается аудит, выполнены 2026-11-15 (раздел 2 — числа, а не оценки).

## 0. Вывод

Численная часть проверена: 33 теста сверяют реализацию с аналитическими пределами и точным HEOM. Но
**модель в текущем виде — качественная**: она правильно показывает тенденции (J/H-сдвиги, обменное сужение,
суперизлучение, рост тушения у поверхности, интерференцию с плазмоном), но не даёт величин, которые можно
количественно сопоставлять с экспериментом. Основных причин три:

1. **две методические ошибки, подтверждённые расчётом** (раздел 2): наблюдаемые считаются не так, как их измеряет
   эксперимент, и форма линии агрегата трактуется по-разному с наночастицей и без неё;
2. **входные параметры выдуманы**, а не откалиброваны по реальной системе (μ, λ, σ, геометрия, спектральная плотность);
3. **нет валидации** — сравнения с опубликованными экспериментами на эталонных системах. Тесты проверяют, что
   уравнения решены верно (верификация), но не то, что решены верные уравнения (валидация).

## 2. Найденные проблемы (по важности)

### П1 (критично, измерено). Наблюдаемые не совпадают с тем, что измеряет эксперимент
`abs_fwhm_cm`, `abs_peak_cm`, `stokes_shift_cm` и др. вычисляются **в каждой реализации беспорядка и затем
усредняются**. Эксперимент измеряет **спектр, усреднённый по ансамблю** (неоднородное уширение входит в ширину).
Проверка (цепочка N = 24, σ = 150 см⁻¹): программа выдаёт FWHM = 65 см⁻¹, FWHM усреднённого спектра — 150 см⁻¹.
Аналогично искажаются стоксов сдвиг и положения пиков для многопиковых полос (у двойной трубки «стоксов сдвиг»
1900 см⁻¹ — сравнение пиков разных полос).
**Исправление:** все спектральные наблюдаемые — из среднего спектра; погрешность — бутстрэпом по реализациям;
устойчивые метрики (центроид, второй момент, доля площади) вместо «положения максимума» для многопиковых полос;
флаг многомодальности.

### П2 (критично, измерено). Разные модели формы линии без НЧ и с НЧ
Без НЧ — кумулянт (немарковская форма, стоксов сдвиг из бани); с НЧ — лоренцианы с полушириной Редфилда.
Проверка на «прозрачной» НЧ (ε = ε_m, обе схемы обязаны совпасть):

| | пик | FWHM | 2-й момент |
|---|---|---|---|
| оболочка N = 300, кумулянт | 18881 | 490 | 310 |
| та же, плекситонная схема | 18893 | 571 (+17 %) | 521 (+68 %) |

Следствия: «голый экситон» на картах скана и «вклад агрегата» содержат расхождение методов; модель
связанных осцилляторов сравнивает величины из разных теорий.
**Исправление (минимум):** опорный спектр агрегата считать в той же схеме (прозрачная НЧ).
**Правильно:** немарковский отклик экситонов в плекситонном расчёте — комплексная функция отклика каждого
экситонного состояния из кумулянта (L_n(ω) + i·KK[L_n](ω)) вместо (ε_n − ω − iγ_n)⁻¹.

### П3 (критично). Извлечение силы связи по пикам там, где второй ветви нет
В примере `shell_scan` вклад агрегата — 1–8 % от поглощения НЧ, в спектре системы один максимум; g = 310 см⁻¹
получено по сдвигам одного пика (rms 64 см⁻¹ сравнимо с самими сдвигами) — **число не определено**.
Кроме того, γ_p взята как FWHM поглощения Au, искажённого межзонными переходами (не лоренциан).
**Исправление:** (а) флаг «вторая ветвь не разрешена» и доверительный интервал g (профиль χ²); (б) подгонка
**формы** спектров (вклада агрегата), а не пиков; (в) **микроскопическое g** без подгонки — проекция переходных
диполей экситонов на поле дипольной моды НЧ (у нас уже есть поле моды и полюс a₁ Ми): g_n = √(ħω_p/2ε₀V_eff)·μ_n·ê,
ω_p и γ_p — из комплексного полюса a₁ (квазинормальная мода), а не из FWHM.

### П4 (высокая). Параметры не откалиброваны
μ = 12 Д, λ = 50 см⁻¹, ω_c = 120 см⁻¹, σ = 150 см⁻¹, плотность и ориентация молекул — условные. Для цианиновых
J-агрегатов (TDBC, PIC) это даёт качественно неверную форму: у мономера сильная вибронная прогрессия
(мода ~1100–1300 см⁻¹, S ≈ 0.3–0.6), а она определяет 0–1-плечо и «вибронное» обменное сужение.
**Исправление:** калибровка по мономеру *той же* молекулы: μ — из интеграла коэффициента экстинкции; спектральная
плотность (обертон + моды) — подгонкой спектров поглощения и ФЛ мономера кумулянтом; τ_rad — Стриклер–Берг;
затем спектр агрегата **предсказывается** без подгонки, и только структурные параметры уточняются.

### П5 (высокая). Связи на 1–1.5 нм точечными диполями
При r ≈ размеру хромофора точечный (и протяжённый) диполь ошибается на десятки процентов, экранирование 1/n²
грубое. **Исправление:** переходные заряды (TrEsp) или куб переходной плотности из TDDFT для конкретной молекулы;
экранирование, зависящее от расстояния.

### П6 (высокая). Структура
Формы идеализированы, упаковка реальных агрегатов (и на поверхности НЧ, с лигандным слоем) неизвестна.
**Исправление:** для валидации — системы с известной структурой (кольца LH2 — PDB; трубки C8S3 — крио-ЭМ);
для НЧ — диэлектрический спейсер (многослойный Ми), реальная плотность покрытия.

### П7 (средняя). Беспорядок
Только некоррелированный диагональный. Реальный — коррелированный в пространстве, недиагональный (разброс
связей), структурный. **Исправление:** корреляционная длина беспорядка, разброс ориентаций/расстояний.

### П8 (средняя). Точность быстрой теории динамики и форм линий
По HEOM: 16–38 % амплитуды и 10–17 см⁻¹ положения для малых агрегатов. **Исправление:** модифицированный Редфилд
(сдвиги и формы), калибровка по HEOM фрагментов той же формы.

### П9 (средняя). Электродинамика НЧ
Квазистатика с поправкой только для l = 1 (пригодна до R ≈ 30 нм); при зазоре 1.5 нм не учтены нелокальность и
spill-out (тушение переоценено, ср. Gonçalves 2020); точечный диполь у металла; одна НЧ без распределения размеров.
**Исправление:** запаздывающая функция Грина сферы (точная, Ми); d-параметры Фейбельмана; многослойная сфера;
усреднение по распределению размеров/форм (из ТЕМ).

### П10 (средняя). Нет излучательных свойств гибрида
Считается распад *в* НЧ, но не излучательное (Парселл) усиление и не спектр ФЛ гибрида. Для флуоресцентных
экспериментов — ключевое. **Исправление:** излучательная скорость через полный дипольный момент (молекула + образ),
квантовый выход у НЧ, спектр ФЛ системы.

### П11 (средняя). Численные сетки и данные
Шаг частот для системы с НЧ в `shell_scan` — 45 см⁻¹ при особенностях 100–300 см⁻¹; таблица Au (Johnson–Christy) —
7 точек на 450–650 нм (линейная интерполяция → изломы). **Исправление:** адаптивная сетка у резонансов, проверка
сходимости положений пиков по сетке; McPeak/Olmon и сплайн по ε.

### П12 (средняя). Неопределённость
Полосы ±SE отражают только конечность выборки беспорядка. Неопределённость параметров не распространяется,
чувствительность не оценивается — графики выглядят точнее, чем есть. **Исправление:** ансамбль по априорным
распределениям параметров → полосы предсказания; индексы Соболя; явная подпись «±SE (disorder sampling only)».

### 7.1 Калибровка на опубликованных данных (v0.6.1)
Открытых данных TDBC не найдено; использованы C8S3 (мономер + нанотрубки) и мероцианин MC1 (мономер, ε в 5
растворителях + J-агрегат). μ калибруется надёжно (MC1: 12.2/11.9 Д). Спектральная плотность по одному поглощению не
определяется (C8S3: стоксов сдвиг модели 14 ТГц против 30 ТГц из статьи) — **нужен спектр ФЛ мономера**. Для
C8S3-нанотрубок предсказание J-полосы требует нового члена — дисперсионного сдвига энергий сайтов, зависящего от
окружения (П5/П6); добавлен в план.

### 7.2 Дисперсионный сдвиг сайтов (v0.7)
Добавлен член Megow et al. и бесшовная геометрия трубки. Для C8S3 он объясняет 60 % J-сдвига без подгонки;
расщепление стенок — с верным знаком. Критерий ±50 см⁻¹ не достигнут: неопределённость протяжённых диполей —
сотни см⁻¹, не учтён контакт с растворителем (~0.1 эВ), ширина завышена из-за бани и беспорядка, взятых из
одного поглощения мономера. Следующий шаг (П5): дисперсионные сдвиги из атомных переходных плотностей.

### 7.3 Атомные переходные плотности (v0.7.2)
С переходными зарядами TD-DFT и калибровкой мономера по поглощению вместе с ФЛ J-полоса C8S3 предсказана с
ошибкой +100…+200 см⁻¹ при неопределённости модели ±50 см⁻¹ (было +900). Критерий ±50 см⁻¹ ещё не выполнен.
Остаются: ширина полосы (на 20–70 % больше измеренной) и неразрешённое расщепление стенок. ФЛ мономера — оцифровка;
нужен исходный файл от авторов.
