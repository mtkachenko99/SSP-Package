# Представление результатов

> Статус: v0.1 (2026-11-11). Стандарты графиков и форматов для отчётов и GUI.

## 1. Общие правила

- Ось энергии: эВ (или см⁻¹ для КР/Бриллюэна, ГГц для BLS) с вторичной осью λ (нм) там, где это принято.
  Для сравнения пиков — всегда в энергетических единицах (ширины в нм зависят от положения).
- Экспериментальные точки — маркеры/тонкая линия с полосой σ; модель — сплошная линия; апостериорная
  предсказательная полоса (68/95 %) — заливка.
- **Каждый график «модель vs эксперимент» имеет панель остатков** (r_i = (y_i − f_i)/σ_i) под основной, с общей осью x и линиями ±1, ±2.
- Подпись: модель (уровень иерархии), набор ε, ключевые параметры, χ²_ν; ссылка на run ID.
- Цветовые палитры — перцептивно равномерные (viridis/cividis) для карт; дивергирующие (RdBu) — для остатков и знакопеременных величин; фиксированные шкалы в сериях.
- Векторный вывод (SVG/PDF) для публикаций, PNG — для быстрого просмотра; данные графика — рядом в CSV/HDF5.

## 2. Каталог стандартных представлений

| Задача | Представление |
|---|---|
| Оптические сечения | σ_ext, σ_abs, σ_sca (и/или Q) на одном графике; для ансамбля — поглощение A или молярная экстинкция |
| Ближнее поле | Карты \|E/E₀\|² (и \|E\|⁴ для SERS) в плоскостях сечения, лог-шкала; статистика горячих точек |
| Идентификация мод | Мультипольное разложение (вклады ED, MD, EQ, MQ, тороидальные) vs λ — составная площадь |
| Параметрические серии | Тепловые карты σ(E, параметр) (размер, AR, n_m, толщина оболочки, T) |
| Сильная связь | Диаграмма антипересечения: положения пиков vs расстройка с ветвями E±, коэффициенты Хопфилда; карты экстинкции/поглощения/рассеяния рядом; таблица критериев |
| Флуоресценция у НЧ | γ_rad/γ₀, γ_nr/γ₀, QY и полное усиление vs расстояние (лог), для ⊥ и ∥ ориентаций и усреднённое |
| QNM | Полюса в комплексной плоскости ω; траектории vs параметр; исключительные точки |
| EELS/CL | Спектры в точках + карты потерь |
| Экситоны vs размер | E₁(D) — сравнение моделей (Брус, непараболическая EMA, k·p, TB/EPM) с эталонными калибровками; оси E vs 1/D² или лог-лог |
| ФЛ | Спектр с декомпозицией (бесфононная линия, фононные повторения, ловушки); Γ(T) с подгонкой Сегалла; E(T) с Варшни/Бозе–Эйнштейн; спектральная плотность S(ω) — палочковая диаграмма |
| КР | Спектры с отнесением мод (неприводимые представления), поляризационные зависимости (полярные графики), Raman-карты (положение/ширина/отношение интенсивностей); для 2D — векторное разложение деформация/допирование |
| Фононы | Дисперсия + проекционная DOS (LO–TO расщепление) |
| Низкочастотный КР / Бриллюэн | Частоты мод (n, ℓ) vs 1/D с выделением КР-активных (ℓ = 0, 2); спектры с декомпозицией по модам; карты поля смещений мод |
| Подгонка/вывод | Corner-plot апостериора, матрица корреляций, профили правдоподобия, трассы MCMC |
| Анализ невязки | Панель остатков; автокорреляция остатков; компоненты PCA/NMF матрицы остатков серии рядом с ∂f/∂θ кандидатов; апостериор δ(λ) модели расхождения; индексы Соболя (столбцы) |
| Обращение | Восстановленное P(R) с полосой неопределённости поверх TEM-гистограммы |

## 3. Форматы данных

- Результаты расчётов: **HDF5** (группы `/config`, `/axes`, `/observables/<name>`, `/fields`, `/meta`) + CSV для простых спектров.
- Экспериментальные спектры: исходный формат прибора + CSV (`x, y, sigma`) + `*.meta.json`.
- T-матрицы: формат обмена T-матрицами (HDF5), если стандарт будет подтверждён.

## 4. Реализация в GUI (Qt6)

Виджеты: спектр + панель остатков (общая ось), тепловая карта, дисперсионная диаграмма, карта поля,
corner-plot. Кандидаты на библиотеку графиков: **Qt Graphs** (преемник Qt Charts в Qt 6.8+, 2D/3D) или
**QCustomPlot** (GPL/коммерческая; быстрые 2D-научные графики, цветовые карты). Решение — при начале разработки GUI.
