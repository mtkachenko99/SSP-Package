## 2026-11-15 · v0.5 (этап C аудита + реалистичные оболочки)
- Геометрия: плотные оболочки (`density_per_nm2`), упорядоченные домены с разбросом директора; молекулы — над
  внешней поверхностью лигандного слоя. Беспорядок: коррелированный (ξ), структурный (ориентации, положения).
- Связи: переходные заряды (TrEsp) из файла; тест — совпадение с точечным и протяжённым диполем в пределах.
- НЧ: слоистая сфера (ядро + диэлектрическая оболочка) с граничным условием Фейбельмана d⊥, динамика каждого
  мультиполя l ≤ 8 по Ми (сфера с оболочкой — BHCOAT); распределение размеров ядра (Гаусс–Эрмит).
- Быстрый решатель для больших N: l ≤ L точно (Вудбери, ранг l(l+3)), старшие l — диагональ в базисе экситонов;
  N = 300: 0.7 % (L = 8), 0.16 % (L = 16) от вклада молекул; N ≈ 1000 с 5 размерами — 2 мин вместо > 4 ч ЦП.
- Излучение: Γ_rad через эффективный диполь Σc_in L_iᵀμ_i (Парселл), тушение −2Im W̃_nn − ΔΓ_rad, квантовый выход
  мономера в каждой точке, ФЛ гибрида при одинаковой поглощённой накачке (`hybrid_emission.csv`).
- Динамика: модифицированный Редфилд (опция); вибронная модель Хольстейна (OPA) для поглощения.
- **Найдено и исправлено при проверке (код этого же этапа, в выпущенные версии не попадало):** решатель слоистой
  сферы терял мультиполи l ≥ 7 (матрица с элементами R^l и R^{−l−2} вырождалась численно) — тушение у поверхности
  занижалось почти вдвое (зазор 1.5 нм: 0.21 вместо 0.38 пс⁻¹); множители Ми для l ≥ 4 считались с потерей точности
  (восходящая рекуррентность ψ_n в BHMIE). Исправлено масштабированием радиальных функций и аналитическим
  квазистатическим пределом a_l; добавлен тест по ряду Герстена–Нитцана до l = 90 (сходимость 10⁻⁶).
- Знак λ-члена модифицированного Редфилда установлен по детальному балансу (проверка 0.995); по сравнению с HEOM для
  димера λ ≈ J ошибка населённостей 0.16 против 0.25 у секулярного Редфилда, равновесие совпадает (0.825 / 0.816).
- Тесты: 32 (экситоны, НЧ+агрегат, HEOM, сканы) + 18 (плазмоника) — все проходят.

## 2026-11-15 · v0.6 (этап B аудита: валидация и калибровка)
- Точный эталон: скорости распада диполя у сферы по теории Ми (`plasmonics/dipole_sphere`), тесты энергобаланса
  и пределов. Программа `software/validation/ssp_benchmark` (purcell, extinction), таблицы в `data/results/benchmarks/`.
- **Исправлено по результатам сравнения:** полная скорость распада у НЧ считалась как Γ₀ − 2Im W — без
  интерференции прямого и рассеянного излучения (ошибка 10–50 % на зазорах 5–20 нм). Теперь Γ_tot = Γ_rad + Γ_abs,
  Γ_abs — поглощение в металле (без радиационного затухания НЧ, с запаздывающим полем молекулы для l = 1).
  Затронуты `molecules_near_field.csv` (decay_to_np, nonrad_to_np, quantum_yield) и `hybrid_emission.csv`.
  Точность для R ≤ 10 нм: Γ_tot ≲ 1.3 %, Γ_rad ≲ 7 %.
- Экстинкция Au-сфер против паспортных данных: без размерного затухания ε завышен в 1.3–1.8 раза; λmax зависит от
  набора констант (±3–5 нм) → в погрешность модели.
- Калибровка по мономеру: подгонка поглощения и ФЛ кумулянтной моделью (мультистарт по моментам), μ из ∫ε/ν̃,
  τ_rad (формула модели = Стриклер–Берг); CLI (`monomer_fit` в JSON), GUI (вкладка Calibration, «Apply to the
  aggregate model»), пример на синтетических данных `examples/monomer_calibration.json`.
- Тесты: 37 + 20, все проходят.

  Остаток 0.11 эВ совпадает с дефицитом исходной работы. Расщепление стенок: знак верный, 191 против 313 см⁻¹.
