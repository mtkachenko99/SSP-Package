# Модель: молекулярные агрегаты произвольной формы и их связь с плазмонной наночастицей

> Статус: v0.2 (2026-11-15), реализовано и проверено автотестами. Реализация: `software/excitons` (ядро + CLI `ssp_aggregate`),
> `software/plasmonics` (материалы, Ми, квазистатика сферы/сфероида).
> Предшественник: `software/scripts/testcalc.ipynb` (феноменологическая прикидка), описание — `опис програми.docx`.
> Цель — заменить подгоночные параметры ноутбука величинами, выводимыми из физической модели, и дать
> численно контролируемую точность при изучении зависимости свойств от формы агрегата и наночастицы.

## 0. Что изменилось по сравнению с ноутбуком

| Величина | Ноутбук | Программа |
|---|---|---|
| Связь J_ij | J0·(r0/r)³·κ, J0 произвольно | μ [D], r [нм], экранирование; точечный или протяжённый диполь; режим `legacy_J0` для сравнения |
| Ширины линий, стоксов сдвиг | γ_abs, γ_em, Δ — вручную | кумулянтная теория: g_n(t) = Σ_i c_in⁴ g(t); сдвиг 2λ_n; сужение обменом выводится |
| Скорости релаксации | W0·J(Δ)·overlap, безразмерные | секулярный Редфилд в пс⁻¹, k = Σ_i c_in² c_im² C(ω_nm) |
| Излучательный распад | 0.02·f | Γ_n = n ω_n³|μ_n|²/(3πε₀ħc³) или по τ мономера |
| Стационарные населённости | решение с костылём P = max(P,0) | невырожденная система (K − Γ)P = −pump; кинетика P(t) через симметризацию |
| Плазмон | ω_p = 17500 − 1800(AR−1), g0 вручную | ε(ω) металла (refractiveindex.info) + форма НЧ (сфера: Ми; сфероид: квазистатика + MLWA) |
| Связь с плазмоном | 1/(d+1)³ | функция Грина НЧ: мультипольное разложение по всем l ≤ L_max для каждой пары молекул |
| Плекситонный спектр | сумма лоренцианов эрмитовой 1+n модели | линейный отклик системы «агрегат + НЧ»: σ_ext, σ_abs, σ_sca раздельно |
| Ансамбль | 30 реализаций | до заданной статистической погрешности, с полосами ±SE |
| Эталон | — | HEOM (численно точный) для малых агрегатов |

## 1. Единицы

Энергии — см⁻¹; длины — нм; дипольные моменты — Дебай; скорости — пс⁻¹; время в выводе — пс.
Внутренне ħ = 1, частота в см⁻¹ трактуется как угловая в единицах 2πc·(1 см⁻¹), единица времени
t_u = 1/(2πc·1 см⁻¹) = 5.3088 пс. Связь D²/нм³ → см⁻¹: 5.0341 (1/(4πε₀)).

## 2. Геометрия

13 форм ноутбука перенесены с теми же параметрами (`linear_chain`, `ring`, `elliptic_ring`, `cylinder`,
`double_wall_tube`, `elliptic_tube`, `helix`, `ribbon_2d`, `brick_layer_sheet`, `stacked_rings`,
`tube_radial_disorder`, `tube_variable_pitch`, `tapered_tube`). Длины — нм. Добавлено размещение агрегата
относительно НЧ (сдвиг, поворот) и проверка, что молекулы не попадают внутрь частицы.

## 3. Гамильтониан Френкеля

H = Σ_i ε_i |i⟩⟨i| + Σ_{i≠j} J_ij |i⟩⟨j|, ε_i = E_mono + δ_i, δ_i ~ N(0, σ) — статический беспорядок;
E_mono — **вертикальная** энергия перехода мономера (максимум поглощения при слабой связи с баней).

- Точечный диполь: J_ij = f_s · 5.0341 · μ² [μ̂_i·μ̂_j − 3(μ̂_i·r̂)(μ̂_j·r̂)]/r³, f_s = 1/n² (экранирование оптической средой; задаётся явно).
- Протяжённый диполь (Kuhn): заряды ±q = μ/l на расстоянии l вдоль μ̂; J = f_s Σ q_a q_b / r_ab. Важен при r ≲ 2l (в ноутбуке r ≈ 1 нм при μ ≈ 14 Д).
- `legacy_J0`: J = J0 (r0/r)³ κ — точное воспроизведение ноутбука.

## 4. Баня и формы линий

Каждый сайт линейно связан с собственной (некоррелированной) гармонической баней со спектральной плотностью J(ω):
- Друде–Лоренц: J(ω) = 2λω_cω/(ω² + ω_c²);
- омическая с экспоненциальным обрезанием (как в ноутбуке): J(ω) = (πλ/ω_c) ω e^{−ω/ω_c};
- плюс недемпфированные колебательные моды (Хуанг–Рис S_k, ω_k, γ_k) — броуновские осцилляторы.

Корреляционная функция C(t) = (1/π)∫J(ω)[coth(βω/2)cos ωt − i sin ωt]dω (БПФ), функция уширения
g(t) = ∫₀ᵗdτ∫₀^τ C(τ')dτ'. Проверка: для Друде — аналитическое мацубаровское представление.

Секулярная кумулянтная теория (Zhang–Meier–Chernyak–Mukamel 1998; Renger–Marcus 2002):
- σ_abs(ω) ∝ ω Σ_n |μ_n|² Re∫₀^∞ exp[i(ω − ε_n)t − s_n g(t) − t/(2τ_n)] dt;
- σ_fl(ω) ∝ ω³ Σ_n P_n |μ_n|² Re∫₀^∞ exp[i(ω − ε_n + 2λ_n)t − s_n g*(t) − t/(2τ_n)] dt;
- s_n = Σ_i c_in⁴ (обратное число делокализации), λ_n = s_n λ, 1/τ_n = Σ_m k_{n→m}.
Ширины, сужение обменом и стоксов сдвиг 2λ_n выводятся из делокализации — т. е. **зависят от формы агрегата**.
Ограничения: секулярность, второй порядок по связи с баней в недиагональных элементах; проверяется HEOM.

## 5. Релаксация (Редфилд) и кинетика

k_{n→m} = Σ_i c_in² c_im² C̃(ω_nm), C̃(ω) = 2J(ω)[n(ω)+1] (ω>0), 2J(|ω|)n(|ω|) (ω<0);
детальный баланс выполняется точно. Распад: Γ_n^rad = n_med ω_n³|μ_n|²/(3πε₀ħc³) (или через τ мономера),
Γ^nr — константа. Стационарно: (K − diag Γ)P = −p, накачка p ∝ |μ_n|² (как в ноутбуке) или ∝ |μ_n|² L_n^abs(ω_exc).
Квантовый выход Φ = Σ Γ_n^rad P_n / Σ p_n. Динамика P(t): симметризация K детальным балансом → вещественная
симметричная задача на собственные значения.

## 6. HEOM (эталон)

Иерархические уравнения движения (Tanimura; Ishizaki–Fleming 2009) для баня Друде–Лоренца на каждом сайте,
K мацубаровских членов, глубина L, терминатор для отброшенных мацубаровских членов.
- Линейное поглощение: иерархия векторов когерентности ⟨g|…|e⟩ (дёшево).
- Динамика населённостей: иерархия матриц плотности одноэкситонного блока.
Применяется для N ≲ 10–15 молекул; сравнение с кумулянтом и Редфилдом даёт оценку погрешности быстрых методов.
Для мономера HEOM и кумулянт совпадают точно (тест).

## 7. Наночастица

### 7.1 Материал
ε(ω) из таблиц refractiveindex.info (`tabulated nk`) с кубической интерполяцией по λ, либо модель Друде;
опционально размерное затухание Крейбига γ(R) = γ_b + A v_F/R_eff (по умолчанию выключено).

### 7.2 Сфера
- Точная теория Ми: коэффициенты a_n, b_n (логарифмическая производная, нисходящая рекуррентность) → σ_ext, σ_sca, σ_abs.
- Взаимодействие с молекулами: квазистатическая функция Грина сферы (мультиполи l = 1…L_max, сходимость контролируется),
  дипольный член (l = 1) заменяется точным Ми-поляризуемостью α = (3i/2k³)a₁ (радиационное затухание и динамическая деполяризация).
  Применимость: расстояния молекула–НЧ ≪ λ (ближнее поле), что выполняется для нм-агрегатов.

### 7.3 Сфероид (стержень — вытянутый, диск — сплюснутый)
- Точное квазистатическое решение в сфероидальных координатах: разложение 1/|r−r'| по P_l^m, Q_l^m,
  граничные условия на ξ = ξ₀ дают коэффициенты отклика D_lm(ε) для каждой мультипольной компоненты.
- Дипольные компоненты (l = 1, m = 0, 1) поправляются на запаздывание по MLWA (Meier–Wokaun) вдоль соответствующей полуоси.
- Проверки: сфероид → сфера при AR → 1; поляризуемость из D_1m = формула с факторами деполяризации; разложение 1/|r−r'|.

## 8. Отклик системы «агрегат + НЧ»

Эффективный неэрмитов гамильтониан одноэкситонного блока: H_eff(ω) = H + W(ω) − iΓ_hom (Γ_hom — полуширины),
W_ij(ω) = +(μ_i·∇)(μ_j·∇′)K_ind/(4πε₀ε_m) — взаимодействие диполей i и j через наведённое поле НЧ (знак как у свободной J) (включая i = j: лэмбовский сдвиг и
безызлучательный распад в металл). Локальное поле: E(r_i) = L_i E₀ (усиление ближнего поля).
Полная поляризуемость (взаимность): α_tot(ω) = α_NP(ω) + Σ_ij (L_iᵀμ_i)[(H_eff − ħω)⁻¹]_ij (L_jᵀμ_j)ᵀ.
σ_ext = k Im Tr α_tot/3 (оптическая теорема), σ_sca = k⁴|α_tot|²/(6π)·(усредн.), σ_abs = σ_ext − σ_sca.
Сильная связь возникает без подгоночного g; критерии сильной связи проверяются по трём спектрам раздельно
(см. [plasmonics_polaritons.md §5.2](plasmonics_polaritons.md)). Γ_hom: из Редфилда (время жизни + чистая
дефазировка) или задаётся.

## 9. Выходные величины («параметры формы»)

Для каждой формы (среднее ± стандартная ошибка по ансамблю): энергии и силы осцилляторов экситонов, фактор
суперизлучения |μ_n|²/μ², число делокализации 1/s_n, сдвиг J/H-полосы, положение/ширина/асимметрия полос
поглощения и ФЛ, стоксов сдвиг, квантовый выход, излучательное время жизни, времена релаксации; при наличии НЧ —
σ_ext/abs/sca(ω), расщепление Раби (по каждому спектру), усиление поля и скорости распада у каждой молекулы.

## 10. Верификация (автотесты `ctest`)

Единицы связи; протяжённый → точечный диполь при r ≫ l; кольцо — аналитический циркулянтный спектр;
g(t) БПФ vs аналитика Друде; площадь линии = 1; детальный баланс; стационар → Больцман при Γ → 0;
HEOM vs кумулянт (мономер, точно) и vs Редфилд (слабая связь); Ми: предел Рэлея, сохранение энергии без потерь;
сфера: предел плоского зеркала (сдвиг −1/4 и −1/8 μ²/d³); поле на оси сферы; сфероид ↔ сфера; поляризуемость сфероида.

## 11. Ограничения и что дальше

Квазистатика для W при больших НЧ (> 100 нм) и больших расстояниях; сфероиды с очень большим AR (сходимость ряда);
одноэкситонное приближение (нет биэкситонов); некоррелированные бани; HEOM только Друде. Следующие шаги:
Qt6 GUI, модифицированный Редфилд, полный (несекулярный) Редфилд, произвольная форма НЧ (BEM).

бани Друде (C(t) сингулярна при t → 0 — друдевская часть теперь аналитически).

**Точность быстрой теории относительно HEOM** (`examples/heom_benchmark.json`: N = 6, μ = 6 Д, λ = 35 см⁻¹,
ω_c = 106 см⁻¹, 300 K; HEOM сошёлся: L 4→6 и K 1→2 меняют спектр ≤ 0.3 %):
- поглощение: max|кумулянт − HEOM| = 16 % (кольцо) и 38 % (J-цепочка) от пика; пик HEOM на 10–17 см⁻¹ ниже —
  секулярная кумулянтная теория не учитывает индуцированный баней сдвиг экситонных уровней и переоценивает уширение
  узкой J-полосы;
- населённости (1 пс): |ΔP| ≤ 0.03 (цепочка), ≤ 0.2 (кольцо, сильнее смешанные состояния).

**Вывод для методологии (M3, M8):** при λ ~ 30–50 см⁻¹ и |J| ~ 100–400 см⁻¹ форма и положение узких J-полос из
кумулянт+Редфилд имеют систематическую погрешность ~10–20 см⁻¹ и до десятков процентов по амплитуде. Для
количественного сравнения с экспериментом — калибровать по HEOM на малых фрагментах той же формы и/или перейти к
модифицированному Редфилду (следующий шаг разработки).

## 13. Молекулярная оболочка на НЧ и сканы параметров (v0.3)

**Форма `particle_shell`.** N молекул на расстоянии `gap` по нормали от поверхности сфероида (полуоси берутся из
раздела `nanoparticle`, если не заданы явно). Точки равномерны по площади: последовательность Фибоначчи по азимуту и
обращение функции распределения площади dA ∝ sinθ·√(c² sin²θ + a² cos²θ) по полярному углу; `theta_max_deg` < 180° —
«шапочка». Диполи в касательной плоскости: случайно (0), по φ̂ (1), по θ̂ (2) или по нормали (3), `tilt_deg` — наклон к
нормали. Проверка: зазор по нормали выдерживается до 1e-6 нм, половина точек в верхней полусфере (±5 из 2000).

**Скан** (`"scan": {"parameter", "from", "to", "steps" | "values", "also_set"}`): для каждого значения выполняется полный
расчёт (папки `scan_NN`), затем строятся карты σ(ν̃, параметр) для системы (экстинкция, поглощение, рассеяние, вклад
агрегата = система − НЧ) и для агрегата без НЧ, таблица наблюдаемых от параметра.

**Ветви и сила связи (уточнено на этапе A, см. аудит).** В каждой точке: ω_p, γ_p — полюс дипольной моды НЧ (подгонка
α ≈ A/(ω_p²−ω²−iγω) + B; FWHM поглощения Au искажена межзонными переходами); микроскопическая коллективная связь
g² = (A/2ω_p)·Tr K_a, W^(l=1,a) = α_a·K_a — не требует разрешённых пиков и не зависит от беспорядка. Ниже — прежняя
подгонка по пикам (теперь с интервалом и флагом разрешённости ветвей); исходное описание: ω_p, γ_p — максимум и FWHM поглощения одной НЧ; ω_x, γ_x — максимум и FWHM
поглощения агрегата без НЧ; гибридные пики — локальные максимумы спектров системы. Модель двух связанных осцилляторов
H = [[ω_p − iγ_p/2, g], [g, ω_x − iγ_x/2]], ветви ω± = Re eig H; g подгоняется по всем найденным пикам скана
(сетка + золотое сечение; пики дальше (γ_p+γ_x)/2 + 300 см⁻¹ от ветвей не учитываются). Отдельно для поглощения,
экстинкции и рассеяния. Критерии (γ — FWHM, в точке наименьшей расстройки): видимое расщепление 2g > (γ_p+γ_x)/2;
антипересечение (за исключительной точкой) g > |γ_p − γ_x|/4; кооперативность C = 4g²/(γ_pγ_x).
**Правило методологии:** сильная связь утверждается только по спектру поглощения; расщепление, видимое лишь в рассеянии
или экстинкции, недостаточно (интерференция Фано / индуцированная прозрачность).
Проверка: подгонка восстанавливает g по синтетическим ветвям с точностью < 0.5 см⁻¹.

**Производительность.** Для сферы отклик зависит только от l: W = Σ_l D̂_l(ω)·G_l с предвычисленными N×N матрицами
G_l = Σ_m w_lm V Vᵀ — в ~50 раз быстрее при L ≈ 100. Узкое место при N ≳ 1000 — LU-разложение N×N на каждой частоте и
реализации (O(N³)). Реальная плотность J-агрегатной оболочки (~1 молекула/нм²) для R = 20 нм означает N ≈ 6000 —
это требует редуцированного базиса (следующий шаг разработки).

## 14. Единая теория отклика (этап A)

В расчёте «агрегат + НЧ» диагональ экситонного блока — обратная кумулянтная резольвента a_n(ω) = −i/X_n(ω),
X_n(ω) = ∫₀^T exp[i(ω − ε_n)t − s_n g(t) − Γ_n t/2] dt, так что при W → 0 спектр системы совпадает со спектром агрегата
без НЧ (тест < 1 %). Блок решается в базисе экситонов: (diag a_n + Uᵀ W U) X = Uᵀ M. Спектральные наблюдаемые — из
усреднённого по ансамблю спектра с бутстрэп-погрешностью; кинетика — среднее по реализациям.

## 15. Этап C: реалистичная оболочка, лиганды, излучение, динамика (v0.5)

**Слоистая сфера.** Ядро ε(ω) + диэлектрическая оболочка (лиганды/спейсер, n_s) + условие Фейбельмана на поверхности
металла: ε_in∂φ_in = ε_out∂φ_out, φ_out − φ_in = −d⊥(∂φ_out − ∂φ_in). Для каждого l решается линейная система по
слоям с радиальными функциями (r/b)^l, (b/r)^{l+1} (b — внешний радиус) — без масштабирования система вырождается
при l ≳ 7. Отклик D̂_l умножается на динамический множитель f_l = a_l^Ми / a_l^{qs} (l ≤ 8), a_l^{qs} =
i(l+1)x^{2l+1}D̂_l/[l(2l+1)!!(2l−1)!!]; Ми для сферы с оболочкой — BHCOAT с устойчивой нисходящей рекуррентностью.
Проверки: однородный предел до l = 60; оболочка с ε = ε_m; линейный по d⊥ красный сдвиг; f_l → 1 при x → 0;
самодействие радиального диполя = ряд Герстена–Нитцана Σ(l+1)²D̂_l b^{2l+1}/r^{2l+4} (10⁻⁶).

**Большие N.** W = V diag(d) Vᵀ, V — N × T проекций мультипольных градиентов. В базисе экситонов при l ≤ L —
низкий ранг (2T_L = L(L+3)), при l > L — только диагональ Σ_t d_t (Ṽ_nt)². Система решается по Вудбери:
X = Y − Z(I + δ∘BᵀZ)⁻¹(δ∘BᵀY). Авто-выбор: L из (b/(b+gap_min))^{2L} < 10⁻², но L(L+3) ≤ N/4. Приближение:
недиагональная (в базисе экситонов) часть старших мультиполей; при L = 8 и зазоре 1.5 нм ошибка 0.7 %, при L = 16 —
0.16 % (тест `FastSolverMatchesExact`).

**Распределение размеров.** Спектры — взвешенная сумма по узлам Гаусса–Эрмита R_k = R(1 + σx_k); молекулы
сдвигаются вместе с поверхностью (зазор сохраняется), экситонные состояния берутся из исходного агрегата
(изменение J ~ σ не учитывается); затухание Крейбига пересчитывается для каждого R_k.

**Излучение гибрида.** Для экситона n: Γ_rad^NP = Γ_rad,n·|Σ_i c_in L_iᵀμ̂_i|²/|μ_n/μ|² (излучение через НЧ в дипольном
приближении для НЧ), полный дополнительный распад −2Im W̃_nn, безызлучательный в металл
Γ_nr,NP = Γ_rad,n − 2Im W̃_nn − Γ_rad^NP ≥ 0. Величины интерполируются по 12 узлам энергии. Стационарные
населённости с Редфилдом, QY = ΣΓ_rad^NP P_n при нормированной поглощённой накачке (сравнение с агрегатом без НЧ при
той же поглощённой мощности, т.е. без учёта усиления поглощения). Проверки: предел Γ_rad/Γ₀ = |1 + 2α/r³|² для
радиального диполя вдали от сферы; прозрачная НЧ — QY и спектр совпадают с агрегатом без НЧ; тушение у поверхности.

**Модифицированный Редфилд** (Zhang–Mukamel 1998, Yang–Fleming 2002), некоррелированные одинаковые бани:
k_{M→N} = 2Re∫exp[iΩt − Λg(t)]{p g̈ − [(q₁−q₂)ġ + 2iλq₁]²}dt, Ω = ε_M − ε_N − 2λ(a − p), Λ = a + b − 2p
(a, b — IPR состояний, p = Σc²c², q₁ = Σc_N c_M³, q₂ = Σc_N³c_M; g — в соглашении Mukamel, Im g → −λt).
Равновесие — по ε_n − λs_n. Проверки: λ → 0 — обычный Редфилд (3 %); детальный баланс (0.5 %); димер λ = J —
ближе к HEOM, чем секулярный Редфилд.

**Хольстейн (OPA).** Базис |n, ν⟩, одна мода ω₀ с S на молекулу; диагональ H_nn − Sω₀ + νω₀ (первый момент
мономера сохраняется), связи J_nm F_νF_ν', F_ν — факторы Франка–Кондона; форма линии каждого вибронного
состояния — кумулянт по остальной бане с IPR по сайтам и скоростью ухода ближайшего по энергии электронного
экситона (Редфилд). Проверки: пуассонова прогрессия мономера, правило сумм,
рост A₀₋₀/A₀₋₁ для J- и падение для H-цепочки. Ограничение: без двухчастичных состояний (точность ~ S·|J|/ω₀).

**Пример** `dense_ligand_shell.json`: Au R = 10 нм + лиганды 1 нм (n = 1.45), 997 молекул (0.6 нм⁻², 12 доменов),
σ = 300 см⁻¹ с ξ = 2 нм, 5 размеров (σ_R/R = 0.1): g = 258 см⁻¹ при γ_p = 1621 см⁻¹, FWHM экситона 860 см⁻¹ —
промежуточная связь (C = 0.19); QY гибрида 4·10⁻⁴ против 0.64 без НЧ (зазор до металла 1.5 нм — тушение
доминирует), время жизни 0.68 пс.

## 16. Этап B: валидация и калибровка (v0.6)

**Точный эталон — диполь у сферы (теория Ми).** `plasmonics/dipole_sphere`: полная и излучательная скорости
радиального и касательного диполя у однородной сферы (Ruppin 1982; Kim–Leung–Liu 1988), расчёт в long double.
Проверки: для непоглощающей сферы Γ = Γ_rad (10⁻⁸; этим зафиксированы знаки), дальний предел Γ → Γ₀, дипольный
предел |1 + 2α/r³|², |1 − α/r³|².

**Сравнение модели с эталоном** (`ssp_benchmark purcell`, Au McPeak, вода, λ = 520/600/650 нм, зазоры 0.5–20 нм,
обе ориентации; таблица — `data/results/benchmarks/purcell_vs_mie.csv`):

| R, нм | max \|ошибка Γ_tot\| | max \|ошибка Γ_rad\| |
|---|---|---|
| 5 | 0.3 % | 1.5 % |
| 10 | 1.3 % | 7 % |
| 20 | 7 % | 23 % |
| 40 | 42 % (зазор 0.5 нм: обрезка l_max = 120), иначе ≤ 30 % | 70 % |

Ошибка Γ_rad — относительная при Γ_rad > 0.2Γ₀, иначе абсолютная в единицах Γ₀ (у касательного диполя Γ_rad ≈ 0).
Сравнение выявило две методические ошибки, исправленные в этой версии:
1. Γ_tot = Γ₀ − 2Im W теряет интерференцию прямого излучения молекулы с излучением наведённого диполя НЧ
   (ошибка 10–50 % на зазорах 5–20 нм даже для R = 5 нм). Теперь Γ_tot = Γ₀|μ_eff/μ|² + Γ_abs, где Γ_abs —
   поглощение в металле: из Im W вычтено радиационное затухание дипольной моды НЧ (оптическая теорема,
   Im α_abs = Im α − (2/3)k³|α|²).
2. Квазистатическое поле молекулы в центре НЧ (1/r³): при kr ~ 0.3 нужны члены 1/r² и 1/r. Для дипольного
   поглощения поле взято запаздывающим, g(k) = e^{ikr}[(1 − ikr)(3n(n·μ) − μ) + (kr)²(μ − n(n·μ))]/r³.
Итог: для R ≤ 10 нм Γ_tot — с точностью ≲ 1.3 %, Γ_rad — ≲ 7 % (McPeak; тест `DecayRatesMatchExactMieForSmallSpheres`,
Друде-золото: Γ_tot ≤ 3 %, Γ_rad ≤ 10 % у резонанса). Для R ≳ 20 нм нужны излучение высших мультиполей и
запаздывание внутри НЧ — это граница применимости модели. В спектрах (матрица W) запаздывание связи молекула–НЧ
пока не учтено; для зазоров ≲ 5 нм это поправка ~(kr)² ≲ 2 %.

**Экстинкция Au-сфер** (`ssp_benchmark extinction`, таблица `au_extinction_vs_size.csv`) против паспортных данных
Sigma-Aldrich (λmax: 5 нм — 510–521, 10 нм — 515–523, 50 нм — 531–535 нм; ε(5 нм) = 1.10·10⁷, ε(10 нм) = 1.01·10⁸
М⁻¹см⁻¹):
- без размерного затухания ε завышен в 1.3–1.8 раза; с Крейбигом A = 1 — 0.85–1.07 (все три набора констант);
- λmax зависит от набора констант: McPeak на ~5 нм синее Johnson–Christy; с цитратной оболочкой 1 нм (n = 1.45)
  Johnson–Christy попадает в диапазон для 50 нм (531 нм), McPeak — для 10 нм (520.5 нм), но ни один набор — для
  обоих. Разброс ±3–5 нм по λmax — неопределённость диэлектрической функции, её надо переносить в погрешность
  модели (П12). Рекомендация по умолчанию: A = 1 для d ≤ 20 нм; спектры считать с двумя наборами констант.
Паспортные диапазоны — партийный разброс реальных (несферичных, полидисперсных) частиц, поэтому это проверка
порядка точности, а не строгий эталон; формулы Haiss et al. (2007) и данные Anger et al. (2006) не сверены с
первоисточниками и в сравнение не включены.

**Калибровка по мономеру** (`excitons/monomer_fit`, CLI: JSON с разделом `monomer_fit`; GUI: File → Calibrate
monomer…). Модель: A(ω) ∝ ω·[L_abs ⊗ G_σ], F(ω) ∝ ω³·[L_em ⊗ G_σ], баня «Друде + броуновские моды», статическое
σ. Реализация: g(t) Друде — аналитически (Мацубара), моды — g(t) с S = 1 на длинном окне (кэш), G_σ — множитель
exp(−σ²t²/2), прямое преобразование Фурье в точках данных (без сетки и интерполяции — иначе шум численного
якобиана). Левенберг–Марквардт с границами параметров; старт по точным правилам моментов кумулянта
(⟨ν̃⟩_abs = E0, ⟨ν̃⟩_abs − ⟨ν̃⟩_em = 2λ_tot, дисперсия = σ² + однородная) и мультистарт по сетке ω_c × S (моменты
не разделяют вклад Друде и мод). μ² = ∫σ/ν̃ dν̃ / P(n) — та же формула, что в σ_abs агрегата (без поправки
локального поля, μ² ∝ n∫ε/ν̃; при n = 1 совпадает с 9.186·10⁻³∫ε/ν̃); τ_rad — по формуле модели при ⟨ν̃⁻³⟩^{−1/3}
спектра ФЛ, совпадает со Стриклером–Бергом. ФЛ, записанная на интервал длины волны, переводится с якобианом λ².
Проверка на синтетических данных с известными параметрами (тест и пример `monomer_calibration.json`): все
параметры в пределах 1–2σ, μ = 9.001 Д (истина 9), τ_rad = 4.89 нс по обеим формулам, χ²_ν = 0.99.
Результат — `aggregate_config_snippet.json` (E0, μ, n, баня) и кнопка «Apply to the aggregate model» в GUI;
σ_inh мономера — верхняя оценка беспорядка сайтов, автоматически не переносится.

**Что требует экспериментальных данных** (критерий этапа B из аудита): спектры поглощения (абсолютный ε) и ФЛ
мономера конкретного красителя и спектр его J-агрегата — тогда J-полоса предсказывается без подгонки
(критерий: положение ±50 см⁻¹, ширина ±20 %); измеренные кривые тушения/усиления от расстояния.

## 18. Зависящий от окружения дисперсионный сдвиг энергий сайтов (v0.7)

**Модель** (Megow et al., PCCP 17, 6741 (2015), arXiv:1412.3554). Ван-дер-ваальсово взаимодействие возбуждённой
молекулы с окружением сдвигает её энергию на ΔE_m = Q·Σ_k V_mk², где V_mk — кулоновская энергия двух
протяжённых диполей с единичными зарядами (длина l, вдоль переходных диполей). Q калибруется по континууму:
при случайных взаимных ориентациях на тех же положениях средний сдвиг равен сдвигу Байлиса
−F(n²−1)/(2n²+1) с n слоя красителя. Энергия сайта:
E_m = E_мономер(растворитель) + F·f(n_растворителя) [возврат к газовой фазе] + ΔE_m + extra.
Отличие от исходной работы: заряды размыты, 1/√(r² + a²), a = 0.3 нм. Без этого почти совпадающие заряды
плотно упакованных соседей дают расходимость: при l = 1 нм отдельные сайты получали до −29 000 см⁻¹. Код:
`dispersion_site_shifts` (ячеечный поиск соседей, cutoff 3 нм), конфиг `exciton.dispersion`, файл
`site_shifts.csv`, поля в GUI (Model → Site-dependent dispersion shift).

**Геометрия `brickwork_tube`.** Кирпичная решётка свёрнута на цилиндр: стопки с шагом 0.5 нм, молекулы длиной
2.08 нм, диполь под углом β к оси трубки, касательно поверхности. Соседи в стопке сдвинуты на ±Δ/2 вдоль длинной
оси (две молекулы в ячейке, Δ = 0.9 нм). Свёртка бесшовная: вектор свёртки — вектор решётки, поэтому R и β
подстраиваются (для C8S3: 3.55 → 3.79 нм и 4.75 → 4.65 нм; 44.3 → 44.4°, 34.5 → 34.7°). Со швом пары на нём
давали ложные ловушки на ~3200 см⁻¹. Проверено: нет пар ближе 0.45 нм, N_внеш/N_внутр ≈ R_внеш/R_внутр,
диполи касательны поверхности.

**Предсказание J-полосы C8S3 без подгонки к спектру агрегата** (`data/experiment/doria2022_c8s3_nanotubes/
aggregate_prediction.json`).

  мономера — верхняя оценка). Трубка 25 нм, 1276 молекул.

| мономер (метанол) | 19224 | — |

- **Экситонная связь при экранировании 0.32 почти не сдвигает полосу** (+114 см⁻¹). Весь J-сдвиг даёт

- **Остаток +900 см⁻¹ (0.11 эВ)** совпадает с дефицитом ~0.1 эВ у Megow et al. Они относят его к неучтённому

  верхняя оценка; баня мономера (λ = 800 см⁻¹) определена по одному поглощению (§17).
- **Чувствительность:** средний дисперсионный сдвиг зависит от l и a. При a = 0.3 нм: l = 0.5 → −5830,

  длиной в микроны; на J-полосу это влияет слабо.

### 18.1 Атомные переходные плотности (v0.7.1)
- Дисперсионный член теперь можно считать по атомному распределению заряда (`exciton.dispersion.charges_file`
  или `use_coupling_charges`) вместо протяжённого диполя. Заряды нормируются на |Σqr| = l, поэтому Q сохраняет
  смысл. Калибровка Q — по случайным поворотам всей молекулы. Проверка: два заряда ±1 на ±l/2 воспроизводят
  протяжённый диполь точно (ΣV² до 10⁻⁹).
- Приближение: форма плотности высших переходов в формуле Megow заменена плотностью S₀→S₁. Это шаг вперёд по
  геометрии (размер и форма π-системы), но не по электронной структуре высших состояний.
- **Переходные заряды по геометрии:** `ssp_aggregate --huckel-tresp molecule.xyz charges.txt [π-заряд]`. Метод —
  Хюккель на π-системе (sp²-C и связанные с ними N, наибольшая связная компонента; параметры Стрейтвизера для N;
  β_CC по длине связи), q_i ∝ c_i^HOMO c_i^LUMO, система молекулы: x — переходный диполь, z — нормаль плоскости.
  Проверка: стрептоцианин — 7 π-центров, 8 электронов, диполь вдоль цепи, Σq = 0.
  TD-DFT-качество потребует внешнего квантово-химического пакета.
- Для C8S3 открыта атомная геометрия (Bondarenko et al. 2020, figshare 10.6084/m9.figshare.12369335, CC BY 4.0;
  B3LYP/6-31G(d,p)). Опубликованных переходных зарядов C8S3 и машиночитаемого спектра ФЛ мономера не найдено:
  ФЛ мономера в метаноле есть только на рисунке 1c в JACS 2025, 147, 6171 (PMC11848924).

## 19. C8S3: калибровка с ФЛ мономера и атомные переходные заряды (v0.7.2)

**Данные:** ФЛ мономера в метаноле оцифрована с рис. 1c работы Kuevda et al., JACS 147, 6171 (2025), CC BY 4.0
(`data/experiment/c8s3_monomer_pl_kuevda2025/`). Геометрия C8S3 (DFT) взята у Bondarenko et al. 2020, figshare,
CC BY 4.0 (`data/experiment/c8s3_geometry_bondarenko2020/`).

**Калибровка мономера по поглощению вместе с ФЛ.** Одна мода с подгоняемой частотой:
E0 = 19907 ± 7, λ_D = 764 ± 14, ω_c = 573 ± 18, σ_inh = 124 ± 3 см⁻¹, мода 1259 ± 7 см⁻¹ (S = 0.196 ± 0.007),
χ²_ν = 1.9. Стоксов сдвиг пиков: модель 608 см⁻¹, измерение 609 см⁻¹. Противоречие из §17 (14 ТГц против 30 ТГц)
снято: исходные «30 ТГц» из текста Doria et al. не соответствуют рисунку Kuevda et al. (17 нм ≈ 18 ТГц).
Две моды дают χ²_ν = 1.8 при сильно коррелированных параметрах и не используются. С фиксированной модой
1150 см⁻¹ χ²_ν = 3.5: остатки структурированы на вибронных плечах.

- **Атомная форма переходной плотности сильно меняет дисперсионный сдвиг:** медиана −2270 см⁻¹ против −1420 у
  протяжённого диполя. Ошибка положения J-полосы уменьшилась с +900 до −135 см⁻¹ (a = 0.15 нм).

- Экситонная связь при экранировании 0.32 даёт узкую полосу (385 см⁻¹, близко к измеренной ширине), но почти не
  сдвигает её. Сдвиг определяет дисперсионный член.

**Переходные заряды TD-DFT** (`software/qc/c8s3_tresp.py`, PySCF CAM-B3LYP/6-31G*, TDA, газовая фаза; хромофор
с метилами вместо цепей, 48 атомов; 50 мин на 16 ядрах). S₁ = 3.23 эВ (TD-DFT завышает энергию цианинов, около
0.8 эВ относительно эксперимента), S₂–S₄ выше 4.7 эВ со слабыми диполями. Подгонка по ЭСП переходной плотности:
относительная ошибка 1.4 %, 29 зарядов на тяжёлых атомах. Плотность протяжённее, чем у Хюккеля
(среднеквадратичная протяжённость вдоль оси 0.49 против 0.35 нм). Используется только форма: заряды
нормируются на μ = 11.4 Д. (Множитель 1/√2 между подогнанным диполем и диполем TD-DFT — нормировка амплитуд TDA
в PySCF; на форму не влияет.)

Итог для C8S3. Модель без подгонки к спектру агрегата воспроизводит J-сдвиг −2100…−2200 см⁻¹ из измеренных
−2220 (ошибка +100…+200 см⁻¹ ≈ 0.012–0.025 эВ). Неопределённость, связанная с размытием зарядов, уменьшилась

протяжённый диполь → Хюккель → TD-DFT. Ширина полосы завышена на 20–70 %, две полосы стенок не разрешаются:
это следующее узкое место (структура и статическая неоднородность дисперсионных сдвигов).
