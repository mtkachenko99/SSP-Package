## 3. Форма линии ФЛ нанокристаллов

- **Однородное уширение:** лоренциан (T₂) + фононные крылья. Ширина одиночной CdSe КТ при 300 K ~50–70 мэВ.
- **Неоднородное:** I(E) = ∫ P(R) σ(R) Φ(E − E(R)) dR, P(R) — лог-нормальное/гауссово; плюс разброс формы и состава.
  Обращение через dR/dE калибровочной кривой (arXiv:1710.01376 [V]). Ловушки: размерно-зависимые QY и сила осциллятора.
- **Стоксов сдвиг:** расщепление тёмный/светлый + реорганизация (2Sħω) + селективность по размеру в ансамбле.
- **Мерцание (blinking):** марковские модели (заряженное/нейтральное, оже-тушение), степенная статистика, FLID,
  байесовский поиск точек смены / HMM. Обзор Efros & Nesbitt, *Nat. Nanotechnol.* 11, 661 (2016) [?].
- **Кинетика:** скоростные уравнения (край зоны, ловушки, тёмное/светлое с больцмановской заселённостью → τ(T),
  оже для мультиэкситонов, пуассоновская статистика ⟨N⟩ = σj). ОДУ / матричная экспонента.
- **Ловушки:** широкая красная полоса = Хуанг–Рис с большим S; атомистика поверхностей (DFT, CP2K).
- **Обзор:** перовскитные НК как источники одиночных фотонов, arXiv:2511.11142 (2025) [V].

## 4. КР-спектры наночастиц

### 4.1 Модель фононного конфайнмента (PCM)
- Richter–Wang–Ley (1981), Campbell–Fauchet (1986): W(q) = exp(−q²L²/2α),
  I(ω) ∝ ∫ |C(q)|² / [(ω − ω(q))² + (Γ/2)²] d³q.
- **Критика** [V]: произвольный α; не учитывает деформацию, реконструкцию поверхности, лазерный нагрев,
  ангармонизм; предсказывает красный сдвиг там, где иногда наблюдается синий; размеры из PCM и из
  экситонного конфайнмента расходятся; нагрев лазером имитирует конфайнмент.
- Модификации: arXiv:0904.3208, arXiv:1711.11467 [V]. **Использовать только как параметрическую подгонку с явными допущениями.**

### 4.2 Атомистические фононы и тензоры КР
- **DFT + тензоры КР** (приближение Плачека): I ∝ |e_i·α'_ν·e_s|²(n+1)/ω_ν; α' из конечных разностей ε
  (phonopy-spectroscopy, vasp_raman.py) или DFPT (QE `ph.x`, ABINIT, CASTEP). Phonopy — центр силовых констант. До ~300–1000 атомов.
- **Модель поляризуемости связей (BPM):** α = Σ по связям; масштабируется до 10⁴–10⁶ атомов с эмпирическими/ML-потенциалами.
  Сравнение моделей поляризуемости: Berger & Komsa, arXiv:2310.13310 [V]. **Лучший кандидат для собственного C++ для крупных НК.**
- **КР из МД** (ангармонизм, T): Фурье автокорреляции поляризуемости (LAMMPS, i-PI) — важно для «мягких» перовскитов.
- **ML-потенциалы и ML-поляризуемость:** MACE, NequIP/Allegro; MACE-OFF (диполи/поляризуемости) [V];
  MACE-Field arXiv:2508.17870 [V]; Lazzaroni, Sharma, Rossi arXiv:2510.04843 [V]; bond-KRR arXiv:2410.14498 [V].
  Из C++ — через LAMMPS (`pair_style mace`/`nequip`, libtorch).

### 4.3 Резонансный КР
- Конечные разности ε(ω_L) по смещениям (BSE/IPA); KHD-сумма по состояниям с экситон-фононными элементами
  (Reichardt & Wirtz, *Sci. Adv.* 2020 [?]).
- **A-член Альбрехта** + волновые пакеты Хеллера — дёшево, переиспользует смещения Хуанга–Риса из §2.
  Естественная собственная модель для LO-обертонов КТ (отношение 1LO/2LO → S).

### 4.4 КР 2D-материалов
Сдвиговые и дыхательные моды (линейная цепочка), разделение E₂g/A₁g для MoS₂, двойной резонанс 2D-полосы графена,
векторное разложение деформация/допирование (Lee et al., *Nat. Commun.* 2012), I_D/I_G (Cançado/Lucchese).

### 4.5 SERS
- **ЭМ-усиление:** G ≈ |E(ω_L)|²|E(ω_S)|²/|E₀|⁴; за его пределами — переизлучение через диадическую функцию Грина,
  нелокальные/квантовые поправки для зазоров < 1 нм. Le Ru & Etchegoin (книга; *PRL* 2006) [?];
  Langer et al., *ACS Nano* 14, 28 (2020) [?].
- **Решатели:** см. [plasmonics_polaritons.md](plasmonics_polaritons.md).
- **Химическое усиление:** TDDFT комплексов молекула–кластер (Schatz, Jensen; DIM/QM) — вне собственной разработки.
- **Оптомеханика SERS:** Roelli et al., *Nat. Nanotechnol.* 11, 164 (2016); Schmidt et al., *ACS Nano* 2016 [?].

## 5. Низкочастотный КР и Бриллюэн: ограниченные акустические колебания

| Метод | Основа | Применимость | ПО / стоимость |
|---|---|---|---|
| **Лэмб (1882), свободная изотропная сфера** | Уравнение Навье, свободная граница; торсионные (TOR) и сфероидальные (SPH) моды (n, ℓ); ν ∝ v_L,T/D | D ≳ 2 нм; ниже ~1–2 нм континуум не работает [V] | Своё, мс (корни + сферические функции Бесселя) |
| **Сфера в матрице / core–shell** | Сшивка смещений и напряжений; комплексные частоты (радиационное затухание). Saviot & Murray | Лиганды, стекло, вода; затухание определяется рассогласованием акустических импедансов | Своё: матрица переноса в сферических координатах |
| **Правила отбора Дюваля** | КР-активны ℓ = 0 (поляриз.) и ℓ = 2 (деполяриз.) SPH; TOR неактивны | Нарушаются для анизотропных/несферических частиц и в резонансе | В коде |
| **Анизотропная упругость: Рэлей–Ритц / Visscher (xyz)** | Полиномиальный базис x^i y^j z^k, полный C_ijkl, произвольная форма (RUS-подход: Visscher et al., JASA 1991; Migliori) | Точно для свободных частиц. Saviot & Murray, *PRB* 79, 214101 (2009), arXiv:0904.2959 [V] — проекция на моды Лэмба | **Первая цель для C++** (обобщённая задача на собств. значения, N ~ 10³–10⁴, секунды) |
| **МКЭ для произвольной формы** | Слабая форма упругости, модальный/гармонический анализ, подложка, PML | Стержни, пластины, бипирамиды, частицы на подложке, фононные кристаллы | FEniCSx, deal.II, MFEM, NGSolve, Elmer |
| **Атомистика (решёточная динамика / МД)** | Силовые константы DFT/ML; проекция на моды Лэмба | НК < 3 нм, размягчение поверхности, лиганды | Phonopy, LAMMPS + ML |
| **Сечение Бриллюэна** | Фотоупругость: δε_ij = −ε² p_ijkl u_kl; σ ∝ |∫ δε(u_ν) e^{iq·r} dV|²; при qR ~ 1 активны ℓ > 2 (BLS коллоидов). Montagna & Dusi | Полимерные/кремнезёмные коллоиды 100–500 нм; массивы наносфер (Kuok et al., *PRL* 90, 255502, 2003 [V]) | Своё: деформации мод из Лэмба/Ритца + численный интеграл |
| **Фонон-плазмонная связь** | Плазмонно-опосредованное усиление ℓ = 0/2 мод в Au/Ag (Bachelier & Mlayah, *PRB* 2004); pump-probe (Hartland) | Металлические НЧ и димеры | Mie + возмущение ε деформацией (∂ω_pl/∂R) |
| **Фононные кристаллы** | PWE, многократное рассеяние, МКЭ-Блох | Коллоидные кристаллы, массивы столбиков | МКЭ, своё PWE |

серия Saviot & Murray в *PRB* 2004–2009 [V].

## 6. Сравнение с экспериментом (кратко; подробно — в методологии)

- Взвешенный МНК (Levenberg–Marquardt, Ceres), **совместная подгонка** спектров с общими параметрами
  (поглощение + ФЛ + низкочастотный КР → общее P(R)). Дыхательная мода ∝ 1/D даёт размер независимо от экситонной калибровки.
- Байес: MCMC (affine-invariant / NUTS), апостериорные предсказательные полосы, сравнение моделей (WAIC, факторы Байеса).
- Анализ остатков: (данные − модель)/σ с моделью шума (Пуассон + шум считывания), автокорреляция остатков, χ²_ν.
- Суррогаты: гауссовы процессы, полиномиальный хаос, индексы Соболя.
- Обратные задачи (P(R) из спектров): Тихонов, NNLS, максимальная энтропия, лог-нормальный приор.
- Глобальная оптимизация: дифференциальная эволюция, CMA-ES (libcmaes), basin hopping.

## 7. Что писать самим, а что делегировать

**Своё (C++), в порядке приоритета:**
1. Семейство EMA (Брус, непараболическая, диэлектрическое ограничение, core/shell, вариационный/CI), Эллиотт 3D/2D,
   Келдыш–Рытова, модельный гамильтониан тонкой структуры.
2. Движок формы линии: производящая функция Хуанга–Риса при конечной T, Γ(T) Сегалла, свёртка с P(R),
   кинетика, A-член Альбрехта.
3. **Акустические колебания:** Лэмб (свободная, в матрице, core–shell), правила Дюваля, **Рэлей–Ритц/Visscher**,
   фотоупругие сечения КР/Бриллюэна — самая ценная собственная часть (поддерживаемых открытых кодов мало).
4. PCM (только как параметрическая подгонка) и BPM-модуль КР по силовым константам/МД.
5. Оценка SERS |E|⁴ на основе Mie / многосферного Mie.
6. Слой подгонки/вывода (см. §6).
7. Второй уровень: сферическая 8-зонная k·p, разреженная sp³s\* TB + CI.

**Делегировать (читать выходные файлы):** Phonopy + QE/VASP (фононы, тензоры КР); BerkeleyGW / Yambo / EPW / exciting
(GW-BSE, экситон-фононные элементы — только для калибровки параметров ε, m*, E_b, S); Octopus / CP2K / NWChem
(TDDFT кластеров, химическое усиление SERS); MACE/NequIP через LAMMPS (КР крупных НК); FEniCSx / deal.II / MFEM
(упругость сложных форм).
