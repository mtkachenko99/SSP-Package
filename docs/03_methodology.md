# Методология исследований

> Статус: v0.1 (2026-11-11). Живой документ: любое изменение фиксируется в [CHANGELOG.md](CHANGELOG.md)
> с датой, причиной и затронутыми разделами. Номера разделов стабильны — на них ссылаются код и отчёты.

## M0. Цель и общий цикл

Цель — количественная модель характеристики наночастицы (НЧ), согласованная с экспериментом в пределах
неопределённостей, и **явный перечень того, что модель не учитывает**. Каждое исследование проходит цикл:

```
 ┌─► M1 постановка ─► M2 данные ─► M3 прямая модель ─► M4 верификация кода
 │                                                         │
 │   M8 уточнение модели ◄─ M7 анализ невязки ◄─ M6 подгонка/вывод ◄─ M5 эксперимент
 └──────────────────────────────┘
```

Цикл повторяется, пока остатки не станут неструктурированными (M7) или пока не будет исчерпан
список правдоподобных латентных переменных.

## M1. Постановка задачи (карточка исследования)

Для каждого исследования заводится `docs/studies/<YYYY-MM-DD>_<краткое_имя>.md` по шаблону
[studies/_template.md](studies/_template.md). Обязательные поля:

1. **Система:** материал(ы), морфология (сфера / core–shell / стержень / чешуйка / кластер), характерные размеры, среда, подложка, лиганды.
2. **Наблюдаемые:** какие спектры (экстинкция, поглощение, рассеяние, ФЛ, КР, низкочастотный КР, BLS), диапазон, разрешение, T, поляризация, геометрия рассеяния.
3. **Гипотеза / вопрос:** что проверяем (например, «расщепление 120 мэВ — сильная связь?»).
4. **Режим и выбор модели** по таблице [02_literature_review.md §1](02_literature_review.md): обосновать уровень иерархии (аналитика → полноволновые → мезоскопические → ab initio). Правило: **начинать с самой простой модели, способной ответить на вопрос**, усложнять только по результатам M7.
5. **Параметры модели**, разделённые на три класса:
   - *известные* (из баз данных, M2) — фиксируются с неопределённостью;
   - *подгоночные* (θ) — с априорными распределениями и физическими границами;
   - *кандидаты в латентные переменные* (M7.3) — изначально выключены или заданы номинально.
6. **Критерий успеха** (M6.4) — заранее, до сравнения с экспериментом.

## M2. Данные: источники, происхождение, качество

### M2.1 Справочные данные
Источники — [01_databases.md](01_databases.md). Порядок предпочтения: экспериментальные курируемые
(COD, RRUFF, refractiveindex.info с указанием автора набора) → расчётные с известным уровнем теории
(JARVIS, MP, Raman DB, C2DB) → справочники. Расчётные величины помечаются уровнем теории
(PBE / PBEsol / OptB88vdW / TBmBJ / GW / BSE), поскольку систематика (например, недооценка щели в PBE)
сама является источником невязки.

### M2.2 Происхождение (provenance) — обязательно
Каждый справочный файл в `data/reference/` сопровождается `*.meta.json`:
`source`, `url`, `record_id`, `retrieved` (дата), `version`/снапшот, `license`, `citation`, `level_of_theory` (если расчёт), `notes`.
Скрипты выгрузки — в `software/data_fetch/`; ручные правки исходных файлов запрещены (только через скрипт преобразования).

### M2.3 Кросс-проверка справочных данных
- Структура: параметры решётки из ≥ 2 источников (эксперимент COD vs DFT); пространственная группа через spglib.
- ε(ω): **всегда ≥ 2 независимых набора** (например, Au: Johnson–Christy, Olmon/McPeak, Babar–Weaver). Разброс между наборами — оценка систематической неопределённости модели материала.
- Упругие константы и плотность: эксперимент vs DFT (MP/JARVIS); скорости звука по уравнению Кристоффеля сверять с литературными.
- Правила отбора КР/ИК: собственный расчёт по группе vs Bilbao SAM.

### M2.4 Экспериментальные данные
Каждый спектр в `data/experiment/` хранится в исходном виде + `*.meta.json`: прибор, спектральное
разрешение (аппаратная функция), калибровка оси (эталон, дата), T, растворитель/матрица, концентрация,
длина пути, геометрия, поляризация, мощность лазера/плотность возбуждения, время накопления,
независимая характеризация образца (TEM/SEM с гистограммой размеров, DLS, XRD, ICP).
**Модель шума** определяется по повторным измерениям (σ(λ)) или из статистики счёта (Пуассон + шум считывания).

## M3. Прямая модель

### M3.1 Модуль материалов
ε(ω, T, R) с выбором набора данных как параметром; интерполяция только в пределах таблицы
(экстраполяция — через аналитическую модель Друде–Лоренца, подогнанную к таблице, с записью параметров).
Размерные поправки (Крейбиг A, d-параметры), легированные п/п (n_e, γ(ω)), лоренцевы экситоны, LST-фононы.

### M3.2 Модель отклика
Уровень по M1.4. Для ансамблей прямая модель включает:
- распределение размеров/форм P(R), P(AR) (лог-нормальное по умолчанию, параметры — подгоночные или из TEM);
- ориентационное усреднение;
- аппаратную функцию прибора (свёртка);
- для ФЛ — неоднородное и однородное уширение, QY(R), селективность возбуждения.

### M3.3 Численная сходимость (обязательна, фиксируется в карточке)
- Ми/T-матрица: n_max (критерий Wiscombe + проверка изменения σ < 10⁻⁶ отн.).
- DDA/BEM/FEM/FDTD: ≥ 3 разрешения сетки, экстраполяция Ричардсона или явная оценка ошибки дискретизации.
- Ансамблевые интегралы: удвоение числа узлов квадратуры до изменения < 0.1 % от σ шума.
- Рэлей–Ритц: рост порядка полиномиального базиса до сходимости низших мод < 0.1 %.
**Численная ошибка должна быть ≪ экспериментальной неопределённости**, иначе она маскируется под невязку.

## M4. Верификация кода (до сравнения с экспериментом)

1. **Аналитические пределы:** квазистатика ↔ Ми при R → 0; Лэмб для изотропного случая ↔ Рэлей–Ритц; Брус ↔ EMA-решатель при ε_in = ε_out; Тэвис–Каммингс в однофотонном пределе ↔ связанные осцилляторы.
2. **Тождества:** σ_ext = σ_abs + σ_sca; оптическая теорема; взаимность; правила сумм (f-sum для ε); положительность Im ε, Im α; причинность (Крамерс–Крониг).
3. **Кросс-код:** сравнение с внешними эталонами (scattnlay, SMUTHI/TERMS, ADDA, MNPBEM, Meep, Phonopy) на одинаковых входах.
4. **Литературные бенчмарки** (воспроизвести рисунки): Myroshnychenko 2008 (Au сфера 40 нм, стержень); кривые Ruppin; Anger 2006; Antosiewicz 2014 (core–shell J-агрегат); сдвиги d-параметров для малых Ag/Na; моды Лэмба (Saviot & Murray); калибровка Yu et al. 2003 для CdSe.
Тесты из п. 1–3 автоматизируются (`ctest`) и прогоняются при каждом изменении кода.

## M5. Эксперимент: требования к данным для сравнения

- Независимая характеризация геометрии (TEM-гистограмма ≥ 200 частиц) — даёт априор на P(R) и проверку вывода.
- По возможности **несколько наблюдаемых на одном образце** (поглощение + рассеяние + ФЛ; ФЛ + низкочастотный КР; КР при нескольких λ_exc) — для совместной подгонки и снятия вырождения параметров.
- Серии по контролируемому параметру (размер, расстройка, T, показатель среды, толщина оболочки) — для дисперсионных диаграмм.
- Отдельные данные для валидации, не участвующие в подгонке (hold-out: например, другая T или другой растворитель).

## M6. Сравнение модели и эксперимента

### M6.1 Предобработка
Вычитание фона (базовая линия — параметризованная, её параметры входят в модель, а не вычитаются «на глаз»),
калибровка оси, приведение к единой сетке через свёртку модели с аппаратной функцией (не через сглаживание данных).

### M6.2 Подгонка
1. Взвешенный МНК (Levenberg–Marquardt) с весами 1/σ² — точечная оценка θ̂ и ковариация.
2. При многомодальности — глобальная оптимизация (CMA-ES / дифф. эволюция) перед LM.
3. **Байесовский вывод** (MCMC: affine-invariant / NUTS) — апостериор p(θ|y), апостериорные предсказательные полосы.
4. **Совместная подгонка** нескольких наблюдаемых с общими параметрами (например, P(R) общая для поглощения, ФЛ и низкочастотного КР).
5. Для дорогих моделей — суррогат (GP / полиномиальный хаос / нейросеть), обученный на сетке прямых расчётов; ошибка суррогата добавляется к σ.

### M6.3 Идентифицируемость
Матрица корреляций параметров, профили правдоподобия; сильно коррелированные пары (например, n_m и R; A Крейбига и σ_R)
либо фиксируются независимыми данными, либо репараметризуются. Без этого шага физическая интерпретация θ̂ запрещена.

### M6.4 Метрики согласия
χ²_ν (ожидание ≈ 1 при корректной модели шума); RMSE и нормированная невязка r_i = (y_i − f_i)/σ_i;
отклонение положений/ширин/интенсивностей пиков с неопределённостями; для дисперсионных зависимостей — ошибка на каждой ветви;
для сравнения моделей — WAIC / LOO-CV / факторы Байеса (штраф за сложность). Метрика на hold-out-данных (M5) — основная.

## M7. Анализ невязки и латентных переменных

### M7.1 Диагностика остатков
- Распределение r_i (нормальность, Q-Q-график), автокорреляция остатков по оси λ/ω (тест Дарбина–Уотсона / Льюнга–Бокса).
- **Структура остатков** (по форме → гипотеза):

| Сигнатура остатков | Вероятная неучтённая причина |
|---|---|
| Избыток на красном крыле плазмонного пика | Агрегация (димеры/цепочки), несферичность, широкое P(AR) |
| Систематика в синей области Au/Cu (< 520 нм) | Межзонные переходы: выбор набора ε, T, кристалличность |
| Ширина пика больше модели, положение верно | Крейбиг A (лиганды, химическое затухание), неоднородное уширение, P(R) |
| Сдвиг пика при верной ширине | Показатель среды/лигандная оболочка, подложка, нелокальность/spill-out (R < 10 нм), заряд НЧ |
| Асимметрия линии | Фано-интерференция, фононные крылья, P(R) асимметричное |
| Дополнительный пик/плечо | Неучтённая мода (мультиполь, димер), примесь, ловушечные состояния, обертон |
| Невязка растёт с мощностью возбуждения | Лазерный нагрев (сдвиг КР-линий, ε(T)), насыщение, мультиэкситоны |
| Расхождение размеров из разных наблюдаемых | Ошибка калибровки E(R), конфайнмент vs деформация, поверхностный слой |

### M7.2 Анализ латентных переменных
1. **Регрессия остатков на метаданные** (T, концентрация, партия синтеза, возраст образца, мощность, растворитель) по всей серии измерений: значимая зависимость → кандидат в латентную переменную.
2. **Разложение матрицы остатков** серии спектров (SVD/PCA, NMF): число значимых компонент = число неучтённых факторов; форма компонент сравнивается с производными модели ∂f/∂θ_k по кандидатам (например, ∂σ/∂n_m, ∂σ/∂AR) — совпадение формы указывает на переменную.
3. **Модель расхождения Кеннеди–О'Хагана:** y = f(θ) + δ(λ) + ε, δ — гауссов процесс; апостериор δ показывает, *где* и *насколько* модель систематически ошибается, не искажая θ (с учётом предупреждения Brynjarsdóttir–O'Hagan об идентифицируемости — ограничивать δ априорами).
4. **Анализ чувствительности** (индексы Соболя, морфологический скрининг) — какие параметры вообще способны объяснить остаток данной формы.

### M7.3 Каталог кандидатов в латентные переменные (пополняется)
Полидисперсность размера/формы; агрегация; подложка; лигандная оболочка (толщина, n, химическое затухание);
набор оптических констант; температура/лазерный нагрев; заряд/допирование; дефекты, двойникование, поликристалличность;
деформация (core–shell рассогласование); окисление/сульфидирование поверхности; распределение эмиттеров по положению и ориентации;
нелокальность/spill-out; диэлектрическое окружение экситона; ловушечные состояния; аппаратная функция и калибровка.

## M8. Уточнение модели

1. Кандидат из M7 вводится в модель **по одному** с физически обоснованным априором.
2. Проверка: уменьшение χ²_ν **и** улучшение WAIC/LOO (не только χ²); исчезновение соответствующей структуры остатков; согласие на hold-out-данных; физическая разумность значения (сравнение с независимыми измерениями, например TEM-оболочка).
3. Если ни один кандидат не помогает — подъём по иерархии моделей (например, Ми → T-матрица → нелокальная модель).
4. Результат фиксируется в карточке исследования: принятые/отвергнутые гипотезы, итоговая модель, остаточная невязка, перечень оставшихся неучтённых эффектов.
5. Изменения, общие для проекта (например, «для Au < 10 нм всегда включать d-параметры»), вносятся в эту методологию через [CHANGELOG.md](CHANGELOG.md).

## M10. Специфика по типам задач (контрольные списки)

**Плазмоника (экстинкция/рассеяние):** ≥ 2 набора ε; Крейбиг; P(R)/P(AR) из TEM как априор; агрегация и подложка — первые кандидаты в латентные; для R < 10 нм — d-параметры/HDM.

**Сильная связь:** приводить все критерии (§5.2 обзора плазмоники); сравнивать экстинкцию, поглощение, рассеяние; проверять, что лоренцева оболочка в Ми воспроизводит расщепление без «сильной связи»; антипересечение по серии расстроек.

**Флуоресценция вблизи НЧ:** распределение расстояний/ориентаций эмиттеров; собственный QY₀; мультиполи до сходимости при малых d; нелокальные поправки при d < 2 нм; различать усиление возбуждения и эмиссии.

**Экситоны в КТ:** калибровочные кривые (Yu 2003 и аналоги) как бенчмарк; диэлектрическое окружение; непараболичность при R < 2–3 нм; тонкая структура и стоксов сдвиг; P(R) общая с низкочастотным КР.

**КР:** правила отбора и поляризационная геометрия; лазерный нагрев (серия по мощности, стокс/антистокс-термометрия); PCM — только как параметрический фит; деформация vs конфайнмент.

**Низкочастотный КР / Бриллюэн:** изотропия vs анизотропия (Рэлей–Ритц при необходимости); матрица/лиганды (затухание, смещение); правила Дюваля и их нарушение; фотоупругие коэффициенты — источник указывать (открытой базы нет); проверка размера по 1/D против TEM.

## M11. Правила, введённые по итогам аудита 2026-11-15 ([reviews/2026-11-15_model_audit.md](reviews/2026-11-15_model_audit.md))

1. **Наблюдаемые — как в эксперименте.** Спектральные величины (положение, ширина, стоксов сдвиг) вычисляются из
   спектра, усреднённого по ансамблю, а не усреднением величин отдельных реализаций.
2. **Одна теория формы линии.** Сравниваемые спектры (агрегат без НЧ и с НЧ, «голый» экситон в модели связи)
   считаются в одной и той же схеме; проверка — «прозрачная» НЧ должна давать спектр агрегата.
3. **Сила связи только при разрешённых ветвях.** g по положениям пиков сообщается лишь при двух разрешённых
   гибридных максимумах и с доверительным интервалом; иначе — подгонка формы спектра или микроскопическое g;
   параметры плазмона — из комплексного полюса моды, а не из FWHM.
4. **Параметры — из калибровки.** μ, спектральная плотность, τ_rad — из спектров мономера той же молекулы;
   «условные» параметры допустимы только для качественных исследований и помечаются в карточке исследования.
5. **Неопределённость — полная.** Полосы ±SE по беспорядку подписываются как таковые; для количественных выводов —
   распространение неопределённости параметров.
