# Открытые базы данных для валидации моделей

> Статус: v0.1 (2026-11-11). Доступность проверялась веб-поиском 2026-11-11.
> **[V]** — подтверждено источником 2024–2026; **[K]** — по известным сведениям, не перепроверено;
> **[?]** — не удалось проверить. Лицензию каждого источника перед включением данных в репозиторий
> перепроверять (у OPTIMADE-провайдеров — эндпоинт `/info`).

Правило проекта: **любое справочное число в расчёте имеет происхождение** (источник, версия/дата
выгрузки, идентификатор записи, лицензия). См. [03_methodology.md](03_methodology.md), §«Происхождение данных».

## Рекомендуемый базовый набор

1. **refractiveindex.info** (CC0, YAML) — канонический источник ε(ω); подключить как git-submodule/зеркало.
2. **COD** + **MC3D/OPTIMADE** — структуры (gemmi), симметрия — spglib.
3. **JARVIS-DFT** (Figshare JSON, без ключа) — ε(ω) полупроводников, эфф. массы, Cij, ИК/КР.
4. **Computational Raman Database** (CC BY 4.0) — тензоры КР; валидация по **RRUFF** (зеркалировать).
5. **Materials Project API** (бесплатный ключ) — статические ε, Cij, фононы; + de Jong 2015 (Dryad).
6. **C2DB** — экситоны 2D (BSE), КР, плекситонные системы.
7. **Bilbao SAM / Polarization Selection Rules** — проверка правил отбора.
8. **FPbase** + **PhotochemCAD** — флуорофоры; **Yu et al. 2003** — калибровка размеров КТ.

## Пробелы (заполнять самостоятельно, с документированием происхождения)
